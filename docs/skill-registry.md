# Skill Registry

Skills חיצוניים נשארים Reference בלבד עד להשלמת רישום, Pinning, בדיקת רישיון וסריקת אבטחה.

## מועמדים קיימים

| מקור | שימוש אפשרי | סטטוס |
|---|---|---|
| `yuliabk/agent-skills` | SDD, אפיון, תכנון, TDD, אבטחה, Observability | Candidate |
| `yuliabk/skill-scanner` | סריקת Skills לפני אימוץ | Candidate |
| `yuliabk/humanizer` | שיפור ניסוח אנושי בתוצרים מאושרים | Candidate |
| `yuliabk/skills` | תבניות Interface ו-UX | Candidate |
| `yuliabk/agents` | Reference לארגון Roles ו-Agents | Reference only |
| `yuliabk/superpowers` | Reference ל-Development workflows | Reference only |
| `yuliabk/agentic-awesome-skills` | קטלוג לאיתור מועמדים בלבד | Catalog only |

## שדות חובה לפני Import

| Field | Description |
|---|---|
| Source URL | המקור המדויק |
| Upstream URL | המקור המקורי, אם מדובר ב-Fork |
| Pinned revision | Commit SHA קבוע |
| License | רישיון והגבלות הפצה |
| Scan date | מועד סריקת אבטחה |
| Scan result | Pass, Review או Reject |
| Data access | קבצים, Network, Secrets וכלים |
| Owner approval | מי אישר ובאיזה תאריך |
| Status | Candidate, Approved, Installed, Deprecated |

## מדיניות

- אין להעתיק קטלוג Skills שלם לתוך המאגר.
- מייבאים רק Skill שמשרת Use Case מאושר.
- מעדיפים Fork או Vendor copy עם Revision קבוע על פני Download דינמי.
- אין להריץ Installer או Script חיצוני לפני סקירה.
- כל שינוי מקומי ב-Skill מתועד ומופרד משינויי Upstream.
