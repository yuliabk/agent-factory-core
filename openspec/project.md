# Project Context

## Vision

Agent Factory Core מאפשר ל-Owner יחיד לאפיין, לבנות, לבדוק ולשכפל סוכני AI עבור ארגונים בשיטת SDD ו-OpenSpec, עם מינימום קוד ובקרות אבטחה ברורות.

## Constraints

- זמינות עבודה: 6-10 שעות בשבוע.
- תקציב ניסוי: 200-500 ₪ בחודש.
- העדפה: Low-Code וכמעט ללא פיתוח ידני.
- ערוצים עתידיים: Website chat, Email, WhatsApp ואוטומציה פנימית.
- סוגי מידע עתידיים: רגיל, חסוי, אישי, רפואי ופיננסי.
- MVP: נתונים סינתטיים או לא רגישים בלבד.

## Roles

- Owner: אפיון, תיעדוף, אישור, QA ומסירה ללקוח.
- Codex: ניתוח, הצעת ארכיטקטורה, כתיבת מפרטים ומימוש משימות מאושרות.
- Client Process Owner: אישור תהליך עסקי, הרשאות ו-Acceptance Tests.
- Security/Privacy Owner: אישור מידע אישי, חסוי או רגיש לפני Production.

## Source of Truth

- `openspec/specs/`: ההתנהגות המאושרת הנוכחית.
- `openspec/changes/`: שינויים מוצעים שעדיין לא הוטמעו ב-Spec הראשי.
- `docs/`: הסברים והחלטות ארכיטקטורה.
- `templates/`: תבניות Intake, Spec ובדיקות קבלה.
